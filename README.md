# txt-format-userscript

TXT 小说阅读格式化油猴脚本（Tampermonkey userscript for formatting local TXT novels in the browser）。

在浏览器里直接打开本地 `.txt` 小说时，自动完成章节识别、段落拼接、异常字符清理和排版美化，并支持暗色模式、原文模式与一键导出 EPUB。

## 功能特性

- 自动识别并拆分章节标题，支持段落内部的内嵌章节（如“。」第二章”）
- 自动统一章节编号风格（如“第032章”“第三十三章”混排时归一），支持“第一百零三章”等中文编号
- 清理私用区（PUA）等无字形字符，避免段首显示方块
- 保留章节标题中的空格，正文中误插入的汉字间空格自动清理
- 智能段落拼接与对话处理，修复标点误删、长标题误拆、引号断句等问题
- 暗色模式、原文模式（关闭自动纠错）
- 侧边栏章节导航、当前章节高亮、阅读进度记忆（跨版本保留）
- 一键导出 EPUB
- 渲染缓存自动管理：版本更新自动重建，旧版本缓存自动清理

## 安装

1. 在浏览器中安装 Tampermonkey 扩展。
2. 打开本仓库中的 `txt format.user.js`，在 Tampermonkey 安装页面确认安装；也可以直接下载文件后拖入浏览器。
3. 重新打开任意 `.txt` 文件即可自动生效。

脚本通过 `@name` + `@namespace` 识别身份，升级版本时直接覆盖安装，不会产生重复脚本。

## 使用

- 油猴菜单：🌓 切换暗色模式、🔄 原文模式、🧹 清除缓存并重载、📚 导出为 EPUB
- 快捷键：`q` / `e` 向上 / 向下翻页

## 版本机制

- `@version` 采用 `YYYY-MM-DD.N`（日期 + 当日序号）格式，是脚本唯一版本来源
- 代码中的渲染缓存版本号自动取自 `@version`，版本更新后渲染缓存自动重建
- 启动时会自动清理旧版本遗留的渲染缓存，避免数据无限累积
- 阅读进度按文件地址保存，不受版本升级影响
